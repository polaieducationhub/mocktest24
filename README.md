## 🌟 Key Features

- 📚 **20 Important Mathematics Questions**: Exact questions from `OD-24.pdf` with no modifications to numerical values or choices.
- 🌐 **English + Odia Bilingual Format**: Both languages rendered with clean typography and high readability (`"ଗଣିତ ଅଭ୍ୟାସ ପ୍ରଶ୍ନାବଳୀ"`).
- ⏱️ **25-Minute Real-Time Timer**:
  - Live countdown (`25:00`).
  - Auditory and visual warning at **5 minutes remaining**.
  - Automatic submission and answer lock when the timer hits `00:00`.
- 🎯 **Official Examination Marking**:
  - Correct Answer: **+1 Mark**
  - Wrong Answer: **-1/3 Mark (-0.33)**
  - Unattempted: **0 Mark**
  - Maximum Score: **20 Marks**
- 🎨 **Testbook-Style Interface**:
  - Four interactive radio-button style options.
  - Interactive **Question Palette (1 to 20)** with 4 live visual states (*Unattempted*, *Attempted*, *Marked for Review*, *Current*).
  - Quick actions: **Mark for Review & Next**, **Clear Response**, **Previous**, **Save & Next**.
- 🛡️ **Submission Confirmation Modal**: Prevents accidental submits; summarizes attempted, unattempted, and flagged questions.
- 📊 **Result & Analytics Dashboard**:
  - Final score out of 20 with negative marking calculations.
  - Accuracy percentage, correct/wrong counts, and time taken.
  - Performance tier feedback.
- 🔍 **Answer Review & Step-by-Step Solutions**:
  - Available strictly after submission.
  - Side-by-side comparison of user's selected choice vs. correct answer.
  - Full mathematical breakdown and explanations.
- 🔊 **Offline Web Audio System**:
  - Built-in sound synthesis using HTML5 Web Audio API (Start, Click, Warning, Submit, Result).
  - Header **Sound ON / OFF** toggle.
  - Zero external `.mp3` files needed.
- 📱 **Community Channels**:
  - [Official YouTube Channel](https://youtube.com/@polaieducationhub)
  - [Official Telegram Channel](https://t.me/polaieducationhub)

## 🚀 How to Host on GitHub Pages (Free Hosting)

### Method 1: Upload via GitHub Website (Simplest, No Git Install Required)

1. Open [GitHub.com](https://github.com) and log in to your account.
2. Click the **+** (plus) icon at the top right and select **New repository**.
3. Name your repository (for example: `odisha-police-mock-test-24`).
4. Set visibility to **Public**, and click **Create repository**.
5. On the new repository page, click **uploading an existing file**.
6. Drag and drop all project files into the upload area:
   - `index.html` *(main application)*
   - `README.md`
   - `.nojekyll`
7. Click **Commit changes**.
8. Go to **Settings** > **Pages** (in the left sidebar).
9. Under **Build and deployment** > **Branch**:
   - Select **main** (or **master**) and folder **/(root)**.
   - Click **Save**.
10. Wait 1–2 minutes. Refresh the page to see your live URL:
    ```
    https://<your-github-username>.github.io/odisha-police-mock-test-24/
    ```

---

### Method 2: Push Using Git CLI / Terminal

If you have Git installed on your computer, open your terminal in this folder and run:

```bash
# 1. Initialize Git repository
git init

# 2. Add all project files
git add .

# 3. Commit changes
git commit -m "Initial commit: Polai Education Hub Mock Test-24"

# 4. Rename default branch to main
git branch -M main

# 5. Link to your GitHub repository (replace with your repo URL)
git remote add origin https://github.com/<your-username>/<your-repo-name>.git

# 6. Push to GitHub
git push -u origin main
```

Then enable **GitHub Pages** under **Settings > Pages > Branch: main > Save**.
